# 无缝纹理生成器

组合石纹、裂纹、苔藓三层 procedurally 生成四边环绕连续的纹理，支持 512 / 1024 导出。

## 使用

- 打开界面：在本目录起任意静态服务器，如 `python3 -m http.server 8000`，浏览器访问 `http://localhost:8000/index.html`（或直接双击打开 `index.html`）。
- 左侧面板调整三层参数（缩放、方向、强度、颜色），主视图实时预览，下方 2×2 平铺预览用于检查接缝。
- 刷子（＋苔藓 / －苔藓 / 压暗 / 提亮）在边缘涂抹时笔迹自动环绕同步到对边。
- 点击「导出 512 / 导出 1024」下载 PNG。

## 一致性验证

```sh
node verify.js [seed]
```

同一 seed 渲染 512 与 1024，将 1024 周期重采样缩小到 512 后与直接输出对比
（RMSE、差异像素比例），并检测三种输出的四边接缝。结果写入 `artifacts/`。

## 无缝与一致性的实现要点

- 所有图案定义在连续瓦片坐标系 `[0,1)²`，与分辨率无关 → 同 seed 任意尺寸采样同一场。
- 值噪声晶格对整数周期取模 → 严格平铺；缩放滑块量化为整数频率。
- 方向通过「周期场 + 环绕采样定向模糊」实现，任意角度不破坏周期性（不旋转采样域）。
- 裂纹随机游走路径与刷子共用环绕 splat：写回坐标取模，越界笔迹绕回对边。
- 重采样使用环绕双线性（`resamplePeriodic`），缩放不在对边间制造接缝。

## 文件

- `generator.js` — 生成核心（浏览器 / Node 通用）
- `index.html` / `app.js` — 网页界面
- `verify.js` — 一致性与接缝验证脚本
