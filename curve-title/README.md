# 曲线标题排版工具 (curve-title)

沿任意贝塞尔曲线排布标题文字的工具，支持中英文混排、自动换行、越界检查，
并导出**可编辑轮廓**的 SVG（每个字形都是独立的 `<path>`，无 `<text>` 元素）。

## 运行

```bash
npm run serve   # http://localhost:8474
```

浏览器打开后即可使用：输入标题文字，调整曲线形状、弯曲强度、字号、
字距、基线偏移、粗细（描边），点击"导出 SVG"下载矢量文件。

## 功能

- **沿曲线排布**：三次贝塞尔曲线 + 弧长参数化，字形按弧长精确定位。
- **急弯保护**：
  - 切线按字形宽度窗口平滑，避免单个字形被折点"别翻"；
  - 相邻字形转角钳制（默认 ≤32°），超限曲率转化为额外前进量；
  - 相邻字形中心的弦距下限保护（≥0.55×平均字宽），间距只增不减，绝不塌缩；
  - 超出曲线末端的字形直接丢弃并计入越界，不会堆叠在终点。
- **中英文混排断行**：
  - 英文/数字按单词断行（单词不拆分），CJK 按字符断行；
  - 支持避头尾（行首禁则：，。！？等；行尾禁则：（《等）；
  - 自动换行到曲线的法向偏移副本（最多 maxLines 行）。
- **越界检查**：超出曲线容纳能力的字符实时计数并警告。
- **可调参数**：字距、基线偏移、弯曲强度、字号、粗细、行数、对齐（居中）。
- **SVG 导出**：纯轮廓 `<path>`（含 transform），可在 Illustrator / Figma /
  Inkscape 中逐字编辑。

## 测试

```bash
npm test                    # 布局引擎单元测试（Node，20 项断言）
node test/export-matrix.mjs # 生成测试矩阵 SVG 到 ../artifacts/svg/
node test/screenshot.mjs    # 无头 Chrome 截图矩阵到 ../artifacts/shots/
```

测试矩阵覆盖：

- **三种曲线长度**：短（≈416px 弧线）、中（≈890px 波浪）、长（≈1505px 弧线）；
- **急弯**：hook 预设满强度，验证不翻面、不塌缩；
- **字号变化**：20 / 48 / 96 px 布局不变式均成立；
- **粗细变化**：描边 0–4px 为纯渲染参数，不改变排版度量（有断言保证）。

## 结构

```
src/curve.js        曲线模型：贝塞尔采样、弧长 LUT、法向偏移
src/text-layout.js  分词、断行（CJK/拉丁/避头尾）、沿曲线排布、急弯保护
src/font-adapter.js opentype.js 字体适配（度量 + 轮廓）
src/svg-export.js   SVG 轮廓导出
src/app.js          浏览器 UI（画布预览 + 控件 + 导出）
test/               Node 测试与可视化验证脚本
assets/             Noto Sans SC 字体（中英文覆盖）
```
